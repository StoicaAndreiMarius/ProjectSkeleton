# AI Usage Disclosure

## Tools used

- **Claude Opus 4.8** (Anthropic), invoked via **Claude Code** CLI (agentic coding).
  Used for: generating the SDL/Silk.NET interop scaffolding, the sprite-sheet animation
  math, JSON data-model classes, and the pixel-art / Tiled-map asset pipeline.

No other AI tools (no GitHub Copilot, no Cursor, no ChatGPT).

## How it was used

- **Agentic coding** — Claude Code wrote the engine-layer files end-to-end based on a
  written spec (the labs in `../instructions/`). Each fully-AI-generated file is wrapped
  in `// AI-generated` … `// end AI-generated` markers, and is listed below.
- **Asset generation** — All PNG sprites, the Tiled `.tmj` / `.tsj` map and tileset, and
  the JSON sprite-sheet definitions are produced by `tools/generate_assets.py` (Python +
  Pillow). The script itself is AI-generated. Per the assignment, generated assets do
  not count toward the C# authorship cap.

## Authorship split

Measured by `// AI-generated` markers across all C# files under the project (excluding
`bin/` and `obj/`):

| Category | Lines | Share |
|---|---:|---:|
| AI-generated (verbatim) | 567 | **34.5 %** |
| Human-authored         | 1077 | 65.5 % |
| **Total**              | 1644 | 100 %  |

Under the assignment's 50 % cap. Recompute with:

```powershell
Get-ChildItem -Recurse *.cs |
  Where-Object { $_.FullName -notmatch "\\(bin|obj)\\" } |
  ForEach-Object {
    $lines = Get-Content $_.FullName
    [pscustomobject]@{ File=$_.FullName; Lines=$lines.Count;
      AI = [bool]($lines | Select-String "// AI-generated" -Quiet) }
  } | Group-Object AI | ForEach-Object { "$($_.Name): $((($_.Group).Lines | Measure-Object -Sum).Sum)" }
```

## Fully AI-generated files

Each of these begins with `// AI-generated` and ends with `// end AI-generated`:

- `GameWindow.cs` — SDL window lifecycle + IDisposable pattern.
- `GameRenderer.cs` — SDL renderer, texture loading via ImageSharp,
  world- and screen-space draw helpers.
- `Camera.cs` — translation-only world↔screen camera with bounds clamping.
- `Models/TextureData.cs`, `Models/GameObject.cs`, `Models/RenderableGameObject.cs`,
  `Models/TemporaryGameObject.cs`, `Models/SpriteSheet.cs` — engine entity hierarchy
  and JSON-driven sprite-sheet container.
- `Models/Data/Level.cs`, `Models/Data/Layer.cs`, `Models/Data/Tile.cs`,
  `Models/Data/TileSet.cs` — Tiled JSON mirror classes (System.Text.Json).

## Human-authored files

- `Program.cs` — entry point and main loop.
- `Input.cs` — keyboard polling + event-driven click / Space / R.
- `Engine.cs` — frame orchestration, level loading, spawning, collisions, HUD,
  win / lose state machine.
